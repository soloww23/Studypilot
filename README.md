# StudyPilot AI V3

Multi-subject AI tutor with subject-aware prompting and screenshot support.

Subjects included:
Math, English/ELA, Spanish, Science, Biology, Chemistry, Physics, History,
Geography, Government/Civics, Economics, Computer Science, French, Study Skills, Other.

## Local setup
1. Install Node.js LTS.
2. Open Terminal in this folder.
3. Run `npm install`
4. Copy `.env.example` to `.env`
5. Put your AI API key in `.env`
6. Run `npm start`
7. Visit http://localhost:3000

Keep `.env` private. Never upload the real API key to GitHub or put it in browser JavaScript.

For online deployment, use a server host that supports Node/Express and environment variables.
